# AgolYad — פונט עברי מקורי

פונט עברי מקורי בסגנון **מונו-ליין עגלגל** עם קצוות מעוגלים (תחושת כתב יד).
27 אותיות (22 בסיס + 5 סופיות) + רווח. שני משקלים.

## קבצים
- `AgolYad-Regular.ttf` — משקל רגיל (עובי קו 33)
- `AgolYad-Bold.ttf` — משקל מודגש (עובי קו 60)
- `build_agolyad.py` — מנוע הבנייה (כל אות = קו-מרכז שמומר לעיגולים חופפים)
- `AgolYad-specimen.png` — דף תצוגה

## בנייה מחדש
```bash
pip3 install fonttools
python3 build_agolyad.py
```

## התקנה
macOS: דאבל-קליק על קובץ ה-`.ttf` → "Install Font".

## שיטה
כל אות מוגדרת כשלד (skeleton) של קווי-מרכז. המתאר נבנה ע"י "הטבעת"
עיגולים חופפים לאורך השלד — מה שנותן קצוות מעוגלים וחללים פתוחים
(ס, ם, פ) באופן טבעי. שינוי רדיוס העיגול = שינוי משקל.
