# חן — לוג חיפושים

זיכרון מתמשך של כל החיפושים שביצעתי. לפני כל חיפוש חדש, אני קוראת את הקובץ הזה (Grep על מילות מפתח) ומחפשת רשומות דומות מ-30 הימים האחרונים.

**פורמט entry:**

```markdown
## YYYY-MM-DD HH:MM | <נושא>
**מילות מפתח:** k1, k2
**שאילתות שנעשו:** "q1", "q2"
**מקורות שנמצאו:**
- [title](URL) — איכות: ⭐⭐⭐⭐ — הערה
- [title](URL) — איכות: ⭐⭐⭐ — הערה
**נבחר:** <מקור + נימוק>
**קובץ ב-Content:** `<filename>.md`
---
```
