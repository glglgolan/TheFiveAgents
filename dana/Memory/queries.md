# דנה — לוג בקשות אנליטיקה

זיכרון מתמשך של כל בקשות הדוחות שעיבדתי. לפני כל בקשה חדשה אני מבצעת `Grep` על הקובץ הזה כדי לבדוק אם כבר יש דוח טרי באותו טווח.

**פורמט entry:**

```markdown
## YYYY-MM-DD HH:MM | <scope>
**שאלה:** <השאלה המקורית>
**טווח:** <YYYY-MM-DD> → <YYYY-MM-DD>
**קובץ דוח:** [reports/file.md](../reports/file.md)
**עיקרי הממצאים:** <שורה אחת>
---
```
