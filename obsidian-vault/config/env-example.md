# .env.example

## מה זה עושה

תבנית לקובץ משתני הסביבה. המשתמש מעתיק קובץ זה ל-`.env` וממלא את הערכים האמיתיים.

משתנים מוגדרים:
| משתנה | תיאור | חובה |
|--------|--------|------|
| `ANTHROPIC_API_KEY` | מפתח ה-API של Anthropic | כן |
| `OPENROUTER_API_KEY` | מפתח OpenRouter לגישה למודלים נוספים | לא |
| `CLAUDE_MODEL` | מזהה מודל Claude לשימוש (ברירת מחדל: `claude-sonnet-4-6`) | לא |
| `MAX_TOKENS` | מגבלת טוקנים לבקשה (ברירת מחדל: 8096) | לא |

## שייך ל

כל הצוות — כל סוכן שמשתמש ב-API זקוק למפתחות אלו.

- [[gitignore]] — `.env` עצמו מוחרג מ-Git
- [[ראובן-מנכל]] — משתמש במפתחות לקריאות API
