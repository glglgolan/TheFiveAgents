## מה זה עושה

קובץ ההגדרות הראשי של הפרויקט — מגדיר את זהות ראובן כמנכ"ל הצוות, מפרט את מבנה הצוות, ומכיל הוראות לסוכן.

מכיל:
- תיאור ראובן כמנכ"ל
- טבלת חברי הצוות (יעל, יובל, חן, המלחין)
- מבנה תיקיות `.claude/` + workspace לכל סוכן (כולל `Scripts/` ו-`composer/`)
- ניתוב משימות (Triggers) לכל סוכן
- שני Flows מלאים: מחקר→תוכן→תמונות, ותסריט→cues→פסקול

Claude Code טוען קובץ זה אוטומטית בתחילת כל session כ"system prompt" של הפרויקט.
