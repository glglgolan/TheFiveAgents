# סקירת הפרויקט — TheFiveAgents

## מה זה עושה

מערכת צוות סוכנים ליצירת תוכן מבוסס AI. המערכת בנויה סביב ראובן — סוכן מנכ"ל — שמקבל בקשות מהמשתמש, מבין מה נדרש, ומחליט אילו סוכנים להפעיל כדי להשלים את המשימה.

הצוות יכול לכתוב, לחקור וליצור תמונות — כל אחד בתחום שלו.

## מבנה הפרויקט

```
TheFiveAgents/
├── CLAUDE.md              ← הוראות ראובן + תיאור הצוות
├── .env.example           ← תבנית משתני סביבה
├── .gitignore             ← קבצים להתעלמות
└── .claude/
    └── skills/            ← סקילס לשימוש הצוות
```
