# AgolYad — פונט עברי מקורי

## מה זה עושה
פונט עברי מקורי בסגנון מונו-ליין עגלגל עם נטייה וגליות (תחושת כתב יד). 27 אותיות + רווח, שני משקלים (Regular / Bold). נבנה ב-fontTools — כל אות מוגדרת כקו-מרכז שמומר לעיגולים חופפים.
