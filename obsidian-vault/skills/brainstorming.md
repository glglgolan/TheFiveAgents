# brainstorming

## מה זה עושה

סקיל **חובה לפני כל עבודה יצירתית** — בניית פיצ'רים, רכיבים, פונקציונליות חדשה. מנחה דיאלוג שיתופי להפיכת רעיון לעיצוב מאושר לפני כתיבת שורת קוד.

שלבי התהליך:
1. חקירת הקשר הפרויקט
2. שאלות הבהרה (אחת בכל פעם)
3. הצגת 2-3 גישות עם trade-offs
4. הצגת עיצוב וקבלת אישור
5. כתיבת מסמך spec → מעבר ל-[[writing-plans]]
