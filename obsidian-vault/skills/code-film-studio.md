# code-film-studio

## מה זה עושה
מסלול חלופי ליצירת סרט קצר **ללא שום מודל AI גנרטיבי**. הוויזואל נכתב ב-Remotion/React/SVG, הקולות הם `say` קלאסי בלבד, והמוזיקה, ה-SFX והליפסינק מסונתזים בקוד (numpy/scipy). הרינדור רץ על CPU בלבד. התבניות: `scaffold.sh`, `render.sh` ו-`templates/`. תזמור רב-סוכנים (8–15 סוכנים) לכן יקר ואיטי; the-video-man מדווח הערכת עלות ומחכה לאישור לפני התחלה.
